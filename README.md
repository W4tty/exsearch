# ExSearch

Builder-first semantic, color, visual, and JEI-style search for the Minecraft Creative inventory.

Target: Minecraft 1.21.1 / NeoForge 21.1.234 / Java 21.

ExSearch enhances the native Creative Search tab with mod, tag, tooltip, registry ID, color, material, shape, use, style, property, similarity, palette, fuzzy, exclusion, and quoted-phrase searching while leaving JEI available for recipes and usages.
